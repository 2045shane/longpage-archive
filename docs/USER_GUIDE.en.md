# LongPage Archive: Installation and User Guide

## 1. What the extension does

LongPage Archive can save the current webpage in four formats:

1. **Full-page PNG** — stitches the complete page into one image.
2. **Paginated PDF** — splits the captured page into portrait A4 pages.
3. **Quick Markdown** — extracts editable article content into one `.md` file while keeping remote image URLs.
4. **Offline Markdown package** — creates a ZIP containing the Markdown file and a local `assets/` image folder.

The extension runs locally in Chrome. No account or API key is required.

## 2. Installation

### Option A: Install the packaged version (recommended)

1. Download [longpage-archive-v0.1.0.zip](https://github.com/2045shane/longpage-archive/raw/refs/heads/main/release/longpage-archive-v0.1.0.zip).
2. Wait for the browser to finish the download.
3. Unzip the downloaded file.
4. Enter `chrome://extensions/` in the Chrome address bar.
5. Enable **Developer mode** in the top-right corner.
6. Click **Load unpacked**.
7. Select the folder extracted in step 3.
8. Optionally, open Chrome's Extensions menu and pin **长页存档** to the toolbar.

Chrome cannot load the ZIP directly; it must be extracted first.

### Option B: Build from source

Node.js 20 or later and Chrome 116 or later are required.

```bash
npm install
npm run build
```

After the build finishes, follow steps 4–7 above and select the project's `dist` folder.

## 3. How to use it

1. Open a regular webpage you want to save.
2. Wait for the main content to load.
3. Click **长页存档** in the Chrome toolbar.
4. Choose an export option:
   - Export full-page PNG
   - Export paginated PDF
   - Export quick Markdown
   - Export offline Markdown package
5. Wait for Chrome to finish the download.

For PNG and PDF exports, the extension pre-scrolls the page to trigger lazy loading, then captures and stitches each viewport. Keep the current tab open until the task completes. A progress panel with a cancel button appears in the bottom-right corner.

## 4. Choosing an export format

| Format | Best for | Notes |
| --- | --- | --- |
| PNG | Sharing the exact page appearance or keeping visual evidence | Complete visual result; may be a large file |
| PDF | Printing, archiving, and paginated reading | A4 pages; text is not selectable |
| Quick Markdown | Editing, research notes, and knowledge-base import | Fast; images still depend on the source website |
| Offline Markdown ZIP | Long-term storage and offline reading | Includes local images; first use requests permission to download page images |

## 5. Permissions

- The extension processes a page only after you click it.
- Download permission is used to save the export you requested.
- The first offline Markdown export asks for optional HTTP/HTTPS site access so article images can be downloaded.
- If you decline that optional permission, PNG, PDF, and quick Markdown export still work.

## 6. API and data safety

- The current version calls no AI API or third-party generative API.
- There is no API-key field and no developer API key embedded in the extension.
- Page content, screenshots, PDFs, and Markdown are processed locally in the browser.
- The extension does not upload page content to a developer-operated server.
- Offline Markdown only requests image URLs belonging to the source page.
- If an optional API-powered feature is added later, users must provide their own API key. The project will not use a developer's personal API key.

## 7. Troubleshooting

### Why can't it capture a `chrome://` page?

For security reasons, Chrome prevents extensions from processing internal pages, settings pages, extension pages, and the Chrome Web Store.

### Why are some images missing from the offline package?

An image may require authentication, block hotlinking, reject cross-origin requests, or no longer exist. The extension keeps the original remote URL and adds the failure to a report inside the ZIP.

### Why can't I select text in the PDF?

The current PDF is generated by splitting the captured page image into A4 pages. Use Markdown export when editable text is required.

### What should I do if a very long page fails?

Close continuously changing popups, videos, or animations and retry after the page becomes stable. PNG output is limited to 32,767 pixels per side and 120,000,000 total pixels.

### How do I update the extension?

Download and extract the new version, replace the old extension folder, then click **Reload** on the extension card at `chrome://extensions/`.
