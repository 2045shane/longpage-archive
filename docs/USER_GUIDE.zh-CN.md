# 长页存档：中文安装与使用说明

## 一、插件能做什么

“长页存档”可以把当前网页保存为四种格式：

1. **PNG 长图**：把整个网页拼接成一张图片。
2. **分页 PDF**：把网页长图按 A4 纵向比例分页保存。
3. **快速 Markdown**：提取网页正文并生成一个可编辑的 `.md` 文件，图片继续使用网页原地址。
4. **离线 Markdown 包**：生成 ZIP，里面包含 Markdown 文件和本地 `assets/` 图片目录。

插件在浏览器本地运行，不需要注册账号，也不需要 API Key。

## 二、安装方法

### 方法 A：安装已打包版本（推荐）

1. 打开项目 GitHub 页的 **Releases**。
2. 下载 `longpage-archive-v0.1.0.zip`。
3. 双击 ZIP 解压，得到插件文件夹。
4. 在 Chrome 地址栏输入 `chrome://extensions/` 并回车。
5. 开启右上角的“开发者模式”。
6. 点击“加载已解压的扩展程序”。
7. 选择第 3 步解压得到的文件夹。
8. 安装完成后，可点击 Chrome 工具栏的拼图图标，把“长页存档”固定到工具栏。

注意：Chrome 不能直接加载 ZIP，必须先解压。

### 方法 B：从源码构建

需要 Node.js 20 或更高版本，以及 Chrome 116 或更高版本。

```bash
npm install
npm run build
```

构建完成后，按方法 A 的第 4—7 步操作，并选择项目中的 `dist` 文件夹。

## 三、使用方法

1. 打开要保存的普通网页。
2. 等网页主要内容加载完成。
3. 点击 Chrome 工具栏中的“长页存档”。
4. 选择一种导出方式：
   - 导出 PNG 长图
   - 导出分页 PDF
   - 导出快速 Markdown
   - 导出离线 Markdown 包
5. 等待浏览器完成下载。

导出 PNG 或 PDF 时，插件会自动滚动网页以触发懒加载，再逐屏截图和拼接。过程中不要关闭当前标签页。页面右下角会显示进度，也可以取消任务。

## 四、四种格式怎么选

| 格式 | 适合场景 | 特点 |
| --- | --- | --- |
| PNG | 分享网页外观、留存证据 | 画面完整，文件可能较大 |
| PDF | 打印、归档、分页阅读 | A4 分页，文字不可选择 |
| 快速 Markdown | 编辑、整理、导入笔记软件 | 速度快，图片依赖原网页 |
| 离线 Markdown ZIP | 长期保存、离线阅读 | 包含本地图片，首次使用需授权读取网页图片 |

## 五、权限说明

- 插件只会在你主动点击后处理当前网页。
- 下载权限用于保存你选择的导出文件。
- 离线 Markdown 首次使用时，Chrome 会申请访问 HTTP/HTTPS 网页资源的权限，用于下载正文图片。
- 如果拒绝该可选权限，PNG、PDF 和快速 Markdown 仍可正常使用。

## 六、API 与数据安全

- 当前版本不调用任何 AI API 或第三方生成式 API。
- 当前版本没有 API Key 输入框，也没有内置开发者 API Key。
- 网页正文、截图、PDF 和 Markdown 都在浏览器本地处理。
- 插件不会把网页内容上传到开发者服务器。
- 离线 Markdown 只会向原网页的图片地址发起下载请求。
- 如果未来增加需要 API 的可选功能，用户必须自行填写自己的 API Key；项目不会使用开发者个人 API。

## 七、常见问题

### 1. 为什么不能截取 `chrome://` 页面？

Chrome 出于安全原因禁止扩展处理浏览器内部页面、设置页、扩展页和 Chrome 应用商店页面。

### 2. 为什么有些图片没有进入离线包？

图片可能受到登录状态、防盗链、跨域限制或资源失效影响。插件会保留原网络地址，并在 ZIP 中写入失败清单。

### 3. 为什么 PDF 里的文字不能选择？

当前 PDF 是把网页长图按 A4 比例分页生成的，因此内容是图片。需要编辑文字时请使用 Markdown 格式。

### 4. 网页很长时导出失败怎么办？

先关闭会持续变化的弹窗、视频或动画，等页面稳定后重试。PNG 单边最大 32,767 像素，总像素上限为 120,000,000。

### 5. 更新插件后怎样生效？

重新下载并解压新版文件，用新版文件夹替换旧文件夹，然后在 `chrome://extensions/` 中点击插件卡片上的“重新加载”。
