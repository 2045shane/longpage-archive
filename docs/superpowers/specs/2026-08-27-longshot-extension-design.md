# 网页长截图与 Markdown 导出扩展设计

## 目标

构建一个可通过 Chrome“加载已解压的扩展程序”安装的 Manifest V3 扩展。用户在普通 HTTP/HTTPS 网页上可以一键导出 PNG 长图、由同一长图分页得到的 PDF、引用网络图片的 Markdown，以及包含本地图片资源的离线 Markdown ZIP 包。

扩展完全在本机运行，不上传页面内容，不要求登录或服务器。

## 首版范围

### 长截图

- 自动预滚动页面，触发常见懒加载内容，再从顶部逐屏捕获。
- 捕获间隔遵守 Chrome `captureVisibleTab` 的频率限制。
- 第一屏保留固定或粘性元素，后续屏隐藏这些元素，避免导航栏和悬浮按钮重复。
- 根据每帧的真实滚动位置裁掉重叠区域，然后拼接为一张 PNG。
- PDF 使用相同拼接结果，按 A4 纵向比例切片；PDF 中的文字不可选中。
- 捕获过程中显示页面内进度条和取消按钮；成功、失败或取消后都恢复原滚动位置和被修改的内联样式。
- 当目标画布任一边超过 32,767 像素，或总像素超过 120,000,000 时停止生成并显示明确错误，不生成损坏文件。

### Markdown

- 使用 Mozilla Readability 从 DOM 克隆中识别标题和正文，不修改原页面。
- Readability 无法给出正文时，依次回退到 `main`、`article`、`[role="main"]` 和 `body`。
- 输出标题、段落、粗体、斜体、链接、图片、列表、表格、引用和围栏代码块。
- 文档顶部包含 YAML 元数据：标题、来源 URL、导出时间。
- 快速 Markdown 下载单个 `.md`，图片使用绝对网络地址。
- 离线 Markdown 下载 ZIP，包含一个 `.md`、`assets/` 图片和图片失败清单；下载失败的图片在 Markdown 中回退为原始网络地址。
- 图片名确定、可去重且不含不安全路径字符。

## 用户界面

弹窗显示当前页面标题、支持状态、四个导出按钮、状态信息和取消按钮。所有可见文案使用中文：

1. 导出 PNG 长图
2. 导出 PDF
3. 导出快速 Markdown
4. 导出离线 Markdown 包

开始任务后禁用其他导出按钮。后台通过状态消息同步进度；即使弹窗关闭，页面内覆盖层仍显示长截图任务状态。

## 权限与隐私

- 常规权限：`activeTab`、`scripting`、`downloads`、`storage`、`offscreen`。
- 不声明永久的全站内容脚本；用户点击扩展后才向当前页注入内容脚本。
- 离线图片需要跨域下载时，由弹窗在该按钮的用户手势中申请可选的 HTTP/HTTPS 站点权限。
- 用户拒绝可选权限时不启动离线包任务，并提示使用快速 Markdown。
- `chrome://`、Chrome 扩展页、Chrome 应用商店等禁止注入的页面显示“不支持此页面”。

## 组件边界

- `src/runtime/content.ts`：页面测量、预滚动、固定元素处理、覆盖层、恢复和正文提取。
- `src/runtime/background.ts`：单任务互斥、截图循环、离屏任务协调、下载和状态广播。
- `src/runtime/offscreen.ts`：图片解码、画布拼接、PNG/PDF/ZIP Blob 生成。
- `src/capture/*`：无浏览器状态的截图帧规划、画布限制和 PDF 分页计算。
- `src/markdown/*`：正文识别、HTML 转 Markdown、图片命名与引用替换。
- `src/ui/*`：弹窗渲染、权限请求、任务启动和取消。

组件通过带 `type` 字段的消息对象通信。计算逻辑保持为纯函数，由单元测试覆盖；Chrome API 只保留在三个运行时入口中。

## 错误处理

- 页面不支持、注入失败、截图频率限制、页面尺寸变化、画布过大、下载失败和图片抓取失败都转换为中文错误。
- 截图任务使用 `try/finally` 请求页面恢复；恢复失败不会覆盖原始错误。
- 同一时间只允许一个任务，重复点击收到“已有任务正在执行”。
- 离线图片允许部分失败，ZIP 内写入 `图片下载失败.txt`，Markdown 对这些图片恢复网络地址。

## 验收标准

- Chrome 能成功加载构建后的 `dist/`，Manifest 无错误。
- 普通长页面可以生成可打开的 PNG；高度和内容顺序正确，无最后一屏重复。
- 同一页面生成的 PDF 画面与 PNG 一致，并按 A4 比例分页。
- 文章页快速 Markdown 包含标题、来源、正文结构和绝对图片链接。
- 离线 ZIP 包含 Markdown 和成功下载的图片，Markdown 使用相对引用。
- 取消截图后页面回到原滚动位置，固定元素样式恢复。
- `npm test`、`npm run typecheck`、`npm run build` 全部通过。

## 明确不做

- 不发布到 Chrome 应用商店，也不包含上架隐私政策页面和正式品牌图标。
- 不支持 `chrome://`、浏览器设置页、扩展页或 Chrome 应用商店页面。
- 不保证提取跨域 iframe 内的可编辑 Markdown；其视觉内容仍可进入截图。
- 不生成可选择文字的打印式 PDF。
- 不提供区域框选、云同步、OCR、批量 URL 或定时任务。
